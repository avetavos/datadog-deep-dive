## คอร์สนี้ทำงานยังไง

<CardGrid>
  <Card title="pipeline หลายชั้น ไม่ใช่ปุ่มเดียว" icon="rocket">

  </Card>
  <Card title="พฤติกรรมปัจจุบัน ที่ verify แล้ว" icon="random">

  </Card>
  <Card title="tag ชุดเดียว สาม pipeline" icon="approve-check">

  </Card>
  <Card title="ไดอะแกรมที่อธิบายได้" icon="puzzle">
